# qGAN convergence investigation

## Correction after faithful tutorial reproduction

The original code was subsequently executed unchanged with its unseeded
sampler and original CDF plots. It reproduces similar approximate learning
behavior to the published tutorial. The published training plot itself ends
near relative entropy 0.42; our unchanged run ends near 0.39 during training.
The earlier interpretation of these nonzero errors as a failure to reproduce
the tutorial was too strong. See `TUTORIAL_REPRODUCTION.md` for evidence and
the executed reproduction notebook. Results below remain valid, but their
strict probability-accuracy criterion is stronger than the tutorial's example.

BiGAN development is held at its current stage while the preliminary Gaussian
distribution experiment is assessed. Neither source notebook is edited.

## Matched experiment

`compare_qgan_convergence.py` loads the actual setup cells from `GAN_01.ipynb`
and `GAN_01_latent4.ipynb`. Each paired run uses identical initial generator
weights, discriminator weights, target grid, learning rate (0.01), Adam betas
(0.7, 0.999), weight decay (0.005), and 1024 sampler shots. The sampler is seeded
for reproducibility; the original notebooks leave its seed unspecified.
Latent draws use a separate seeded RNG, preserving the shared initialization.
The original loss and update order are retained. Only the latent-input circuit
and its output averaging differ between the original and latent-four runs.

The baseline comparison uses 50 epochs for seeds 123456, 42, and 7. A separate
50-epoch run increases the latent batch from four to sixteen for seed 123456;
this is a one-variable test, not a validated recommendation across seeds.
Both latent variants still have four input components per vector. The run label
`latent16` refers to sixteen vectors per batch, not a sixteen-dimensional input.
The original model is also tested for 200 epochs in `convergence_longer`,
changing training duration alone. Its first 50 epochs reproduce the corresponding
baseline run exactly.

## Evaluation

Training-batch entropy is noisy because both latent vectors and finite-shot
counts vary. It is retained for comparison with the notebook, but conclusions
use independent noiseless statevector evaluation every five epochs.

- Original generator: exact probabilities for its learned quantum state.
- Latent generator: the exact marginal over Uniform(-pi,pi)^4, plus a fixed
  independent batch of 256 latent vectors to quantify Monte Carlo error.
- Metrics: KL(generated || target) in nats and total variation distance.
  Both equal zero when distributions match. GAN losses need not approach zero.

For this particular circuit, averaging Ry(+pi/2) and Ry(-pi/2) produces the
same quantum channel as averaging Ry(z) for a uniform angle. The four inputs
therefore need just sixteen combinations to integrate the prior exactly.
This shortcut depends on the circuit using each input once before its ansatz;
it must be reconsidered if the latent encoding changes. The calculation was
independently checked against density-matrix evolution, with maximum absolute
probability discrepancy below 5e-17.

`convergence_results/*.json` stores initial parameters, loss history, evaluated
metrics, and initial/final distributions. `.pt` files store final model weights
(not optimizer state). `summary.json`, `convergence.png`, and `distributions.png`
are generated by the summary script. This investigation tests distribution
learning, rather than only checking that gradients exist.

## Completed 50-epoch comparison

| Seed | Original KL | Latent-four KL | Original TV | Latent-four TV |
| --- | ---: | ---: | ---: | ---: |
| 123456 | 0.4001 | 0.3133 | 0.3679 | 0.3040 |
| 42 | 0.4287 | 0.4069 | 0.3595 | 0.3357 |
| 7 | 0.5583 | 0.3747 | 0.4330 | 0.3206 |

The latent version improves its exact marginal distribution and finishes closer
to the Gaussian than the original for all three paired seeds. However, neither
version converges closely in 50 epochs. Their initial output distributions also
differ, despite identical initial weights, because the latent circuit introduces
an additional input-averaging operation. These results therefore establish
learning and endpoint agreement, not that one architecture optimizes faster.

Fixed 256-vector evaluation differs from the exact latent marginal by TV about
0.026–0.031, much less than the remaining TV of 0.304–0.336 from the target.
Thus the apparent lack of convergence is not merely evaluation noise.

## Larger latent batch

For seed 123456, increasing the batch from four to sixteen vectors improves
the 50-epoch endpoint from KL 0.31334 / TV 0.30404 to KL 0.27614 / TV 0.28205.
The same initial parameters and all other training settings are retained.
This is a modest improvement, not convergence. Runtime grows from about
500 seconds to 1927 seconds in these runs, so the improvement costs almost
four times as much computation. The larger batch has not been replicated
across seeds and has not been made the notebook default.

## Longer-duration original control

With seed 123456 and unchanged settings, the original generator finishes
200 epochs at KL 0.6991 and TV 0.4712, worse than its 50-epoch result (KL
0.4001, TV 0.3679). Its best evaluated KL remains about 0.3838 at epoch 45.
The first 50 evaluation points match the original baseline exactly.
For this seed and configuration, more epochs alone do not solve convergence;
the measured distribution oscillates and deteriorates later in training.
This is a single-seed duration test, not a statement about all longer runs.

## Separate direct-target diagnostic

Because the adversarial control deteriorates, a diagnostic replaces only the
generator objective with direct KL to the known target and leaves D untrained.
The generator circuit, initialization, optimizer settings, shots and latent
batch remain unchanged. This is supervised probability fitting, not a GAN
solution, and it never alters either notebook's training objective.

```powershell
& 'C:/Users/giuse/.conda/envs/DOUBT_QC/python.exe' compare_qgan_convergence.py --epochs 50 --objective direct-kl --output-dir convergence_direct_kl
& 'C:/Users/giuse/.conda/envs/DOUBT_QC/python.exe' compare_qgan_convergence.py --epochs 200 --variants original --objective direct-kl --output-dir convergence_direct_kl_longer
```

At 50 epochs, the original circuit reaches KL 0.1391 and TV 0.1798 with direct
fitting, compared with KL 0.4001 and TV 0.3679 under adversarial training.
This supports investigating the adversarial optimization rather than attributing
all remaining error to circuit capacity. It does not yet establish exact target
representability or successful adversarial convergence.

The original direct-target diagnostic finishes 200 epochs at KL 0.02509 and
TV 0.07922, versus KL 0.69913 and TV 0.47120 for the corresponding adversarial
control. This demonstrates substantially closer target fitting with the same
circuit and optimizer. The latent-four direct-target run at 50 epochs reaches
KL 0.33832 and TV 0.31771, slightly worse than its adversarial counterpart
(KL 0.31334, TV 0.30404). Consequently, replacing the loss is not a demonstrated
fix for the latent generator; that case still needs controlled investigation.

Before changing architecture, a useful next latent-only experiment is to train
using the sixteen quadrature inputs described above. For this circuit they
integrate the same uniform prior exactly, removing latent Monte Carlo variance
while retaining Qiskit Machine Learning, TorchConnector, and shot sampling.
This has not been tested for training and is not yet a recommended notebook
change. The original GAN's adversarial dynamics require separate investigation.

## Decision

Do not assume exact Gaussian probability convergence. The original tutorial's
approximate behavior has been reproduced, so the prior blanket hold should
not be justified as an unresolved tutorial reproduction failure. All planned
comparisons and diagnostics completed with finite
losses, verified parameter pairing, and unchanged source notebooks, but the
adversarial convergence gate remains unmet. Increasing batch size helps only
modestly; increasing epochs alone worsens the original control. The direct-fit
diagnostic shows that the original circuit can approximate the target closely,
while the latent case needs additional controlled training investigation.

Plots and machine-readable results are in `convergence_results/summary.json`,
`convergence.png`, `distributions.png`, `longer_original.png`, and
`direct_target_diagnostic.png`. These are completed experiments, not merely
two-epoch functionality checks.
